# Rhizome 手工冒烟清单

> 每个 Phase 收尾、每次打包发布前全量执行一遍。场景较多，至少覆盖所有标 **[P0]** 的核心项。
> 环境：开发版（npm run electron:dev）与打包版（npm run build 产物）行为存在差异的点已标注。测试曲库建议同时包含 MP3 / FLAC / WAV、中文与含空格路径。

## 一、启动与窗口

- [ ] 启动应用 **[P0]** — 预期：出现 Sdorica 风格启动动画（splash），随后进入主界面"本地音乐"页，无白屏、无控制台报错。
- [ ] 点击标题栏关闭按钮 **[P0]** — 预期：窗口隐藏而非退出，应用驻留系统托盘，音乐不中断，任务栏无窗口。
- [ ] 托盘图标与 tooltip — 预期：托盘区出现 Rhizome 图标，悬停显示"Rhizome · 音乐播放器"。
- [ ] 托盘左键点击 — 预期：主窗口在显示/隐藏间切换。
- [ ] 托盘菜单控制 **[P0]** — 预期：菜单显示当前曲名；上一首/播放暂停/下一首/音量±均生效；"播放/暂停"文案随状态切换；播放时"显示桌面歌词"项可切换歌词窗口。
- [ ] 二次启动 — 预期：不出现第二个实例，已有窗口被还原并聚焦。
- [ ] 全局显隐窗口（Ctrl+\） — 预期：窗口隐藏状态下按键可重新显示并聚焦。
- [ ] 最大化/还原 — 预期：窗口最大化/还原正常，自绘标题栏按钮状态同步。

## 二、播放核心

- [ ] 选择文件导入 **[P0]** — 预期：文件对话框按音频扩展名过滤；多选导入后出现在曲库列表，标题/歌手/专辑/时长正确。
- [ ] 选择文件夹导入 **[P0]** — 预期：递归扫描文件夹内全部音频并导入；重复导入不产生重复项。
- [ ] 播放 / 暂停 **[P0]** — 预期：点击或 Space 切换播放暂停；播放中频谱动、进度条前进；暂停后进度冻结。
- [ ] 上一首 / 下一首 **[P0]** — 预期：←/→ 或按钮切换到播放列表上/下一曲并自动播放。
- [ ] 进度拖动 **[P0]** — 预期：拖动进度条可 seek，时间显示与声音位置一致；滚轮可微调。
- [ ] 音量调节 **[P0]** — 预期：音量控件/↑↓ 键调节生效，范围 0-100%，重启后保持。
- [ ] 列表播放（list）— 预期：末曲播完停止（不自动续播列表）。
- [ ] 列表循环（listLoop）— 预期：末曲播完自动回到首曲。
- [ ] 单曲播放（single）— 预期：曲终后停止，不自动进下一曲。
- [ ] 单曲循环（singleLoop）— 预期：曲终自动重播本曲。
- [ ] 随机播放（random）— 预期：next 按 shuffle 序列前进且首曲不与当前曲重复；**prev 沿 shuffle 序列回退**（不是列表逆序，这是锚定语义）；序列走完后重新洗牌。
- [ ] 系统媒体键 **[P0]** — 预期：键盘媒体键（播放/暂停/上下曲）控制播放（Media Session renderer 生效路径）。
- [ ] AB 循环 — 预期：进度条右键设 A/B 点后区间循环，切歌自动清除。

## 三、歌词

- [ ] 内嵌歌词显示 **[P0]** — 预期：播放带内嵌 LRC 的歌曲，歌曲详情页歌词逐行滚动高亮，当前行带取景框与进度动效。
- [ ] 侧车歌词 — 预期：同名 .lrc / .txt 文件能被识别显示（.txt 为纯文本无高亮时间轴）。
- [ ] 桌面歌词显示 **[P0]** — 预期：Ctrl+' 或界面按钮唤出置顶透明歌词窗口，显示当前行，无边框不占任务栏。
- [ ] 桌面歌词拖动 — 预期：未锁定时按住可拖到屏幕任意位置；重启后位置保持。
- [ ] 桌面歌词锁定 **[P0]** — 预期：锁定后取景框背景消失、鼠标点击穿透（可点到底层窗口）；解锁后恢复可拖动；重启后锁定状态保持。
- [ ] 桌面歌词字号 — 预期：设置页调整字号（10-18）后歌词窗口即时变化，重启保持。
- [ ] 歌词偏移 — 预期：±2000ms 范围 5ms 步进调整，歌词整体提前/延后；重启保持。
- [ ] 歌词进度平滑 — 预期：歌词行内左右消逝线随播放平滑推进（rAF 插值），无肉眼可见跳变；暂停时冻结。
- [ ] 无歌词占位 — 预期：无歌词歌曲不显示异常文本，桌面歌词显示默认占位内容。

## 四、数据

- [ ] 重启恢复播放进度 **[P0]** — 预期：播放某曲至中途，退出应用重新打开，自动恢复该曲与进度（关闭窗口隐藏不算退出）。
- [ ] 播放历史记录 **[P0]** — 预期：同一曲累计收听满 30 秒才计入历史与播放次数；历史页最近 30 条可见，同曲去重置顶。
- [ ] 歌单增删 **[P0]** — 预期：创建歌单、添加/移除歌曲、删除歌单、拖拽排序、"我喜欢"心形收藏均正常；删除确认次数按设置（1/2/3 次）触发。
- [ ] 曲库重启恢复 — 预期：重启后曲库自动恢复（userData JSON 主存储），文件被移动/删除的曲目灰色删除线标记。
- [ ] 备份导出 **[P0]** — 预期：设置页执行备份，选择位置后生成 rhizome-backup.json；包含歌单、历史、偏好。
- [ ] 恢复导入 **[P0]** — 预期：选择备份文件恢复后，歌单/历史/播放次数/偏好设置逐项还原；原文件已不存在的歌曲以缓存元数据灰色标记显示。

## 五、设置

- [ ] 自启动开关 — 预期：开启后系统登录项出现 Rhizome（重启系统验证可选）；关闭后移除；开关状态与系统一致。
- [ ] 快捷键修改 — 预期：修改本地快捷键立即生效（输入框聚焦时不触发）；修改全局快捷键后应用外按键生效（含清空组合键）；重置默认后恢复。
- [ ] 均衡器（EQ）— 预期：10 段均衡器拖动与预设（摇滚/流行/古典/人声增强/电子）切换音色可感知；重启保持。
- [ ] 屏保 — 预期：空闲时间（1-60min 可配）到达后触发屏保动画，任意操作退出。
- [ ] 动作链 — 预期：Alt+1~5 触发对应编程动作序列。
- [ ] 清空数据 — 预期：确认后曲库清空（音乐路径/文件夹 JSON 被删除），应用其余偏好保留。
- [ ] 主题切换 — 预期：暗色/亮色主题全局切换（含桌面歌词配色），重启保持。
